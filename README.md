This projects is a final project for the Bacherlor's degree in Computer Engineering, Telecommunications and Computers at ISEL. The repository is meant to show 
everyone the work done throughout the semester and share the project with other people interesed in learning more about this project.

The repository is divided by different folders containing files accordingly it's type, i.e., 3D_Printing has all blender and stl files created to our models printed 
in a 3D printer.

All circuit simulations were done in LTSpice.
